# PhotoRefSorter v0.5 — Smart Library

레퍼런스 사진을 기반으로 대량의 사진/영상에서 같은 인물을 찾고, 검토 결과를 다시 학습해 갈수록 정리하기 쉬워지는 Windows용 로컬 사진 분류기입니다.

## v0.5 핵심 업그레이드

### 수만 장 고속 처리
- `os.scandir` 기반 빠른 폴더 열거
- 대형 JPEG는 축소 디코딩으로 I/O/메모리 절감
- 1~8개 병렬 얼굴 분석 워커
- SQLite WAL 임베딩 캐시
  - 경로/크기/수정시간이 같으면 원본 사진을 다시 읽지 않음
  - 레퍼런스를 추가하거나 threshold를 바꿔도 기존 얼굴 임베딩 재사용
  - 중간에 중단해도 이미 분석된 사진은 다음 실행에서 캐시 재사용
- pHash 완전 중복 사진은 얼굴 AI 결과 재사용
- 같은 드라이브에서는 NTFS 하드링크 분류 옵션
- 실시간 처리속도, ETA, 캐시 수, 새 AI 분석 수 표시

### 더 정확한 인물 인식
- 인물별 여러 positive 레퍼런스
- 검토에서 “이 사람 아님”으로 지정한 negative 레퍼런스
- 레퍼런스 품질 가중치
- 사람마다 얼굴 변화 폭을 계산해 개별 threshold 자동 산출
- 1위/2위 후보 점수 차이까지 확인해 닮은 인물 오분류 감소
- 레퍼런스 얼굴 품질 자동 평가
  - 얼굴 크기
  - 선명도
  - 검출 신뢰도
  - 정면성

### 검토 → 자동 학습
- 애매한 얼굴/미확인 얼굴을 앱 안의 검토 갤러리에서 확인
- `이 인물로 확정 + 학습` → positive 레퍼런스로 추가
- `현재 후보 아님` → negative 레퍼런스로 추가
- 수정할수록 다음 분류에 바로 반영

### 미확인 인물 자동 그룹
- 등록되지 않은 얼굴을 코사인 유사도 기반으로 자동 클러스터링
- 반복해서 등장한 미확인 인물을 그룹 단위로 표시
- 그룹을 새 인물로 등록하거나 기존 인물에 연결
- 그룹 내부에서 품질 좋고 서로 너무 중복되지 않는 대표 얼굴만 자동 레퍼런스로 선택

### GPU 가속
- Windows에서 ONNX Runtime DirectML 사용 가능 여부 자동 감지
- DirectML 사용 가능 시 SFace 임베딩 추론에 GPU 사용
- 사용 불가하거나 오류가 나면 CPU 경로 사용

### 다양한 미디어
- JPG / JPEG / PNG / BMP / WebP / TIFF
- HEIC / HEIF
- AVIF
- GIF
- RAW: DNG / CR2 / CR3 / NEF / ARW / ORF / RW2 / RAF / PEF / SRW
- 영상: MP4 / MOV / M4V / AVI / MKV / WebM
  - 영상 전체를 프레임마다 읽지 않고 대표 구간을 샘플링
  - 반복 얼굴 임베딩은 합쳐서 저장량/비교량 절감

### 중복/연사 및 관리
- pHash 기반 완전 중복 분석 결과 재사용
- 유사 연사 후보 통계
- 존재하지 않는 원본의 캐시 정리
- 전체 분석 캐시 초기화
- 마지막 분류 작업 되돌리기
- 원본 사진은 삭제/이동하지 않음

## 업그레이드 호환성

v0.4까지 사용하던 `%LOCALAPPDATA%\PhotoRefSorter\people.sqlite3`가 있으면 v0.5 최초 실행 시 새 `library.sqlite3`로 인물/레퍼런스를 자동 이전합니다.

## 추천 사용 흐름

1. `인물` 탭에서 사람 이름과 레퍼런스를 등록합니다.
2. `대량 분류`에서 사진 폴더를 선택해 최초 스캔합니다.
3. `검토 / 학습`에서 애매한 결과를 빠르게 수정합니다.
4. `미확인 그룹`에서 자주 등장하는 새 인물을 한 번에 등록합니다.
5. 다시 분류하면 기존 사진의 얼굴 임베딩 캐시를 그대로 사용해 빠르게 재매칭합니다.

## 대량 라이브러리 팁

- 첫 스캔은 실제 얼굴 AI 분석이 필요하므로 시간이 걸립니다.
- 두 번째 스캔부터 변경되지 않은 파일은 디코딩과 얼굴 AI를 건너뜁니다.
- SSD에서 가장 빠릅니다.
- CPU 모드에서는 4~6개 워커부터 시작하는 것을 권장합니다.
- DirectML GPU 모드에서는 1~2개 워커가 보통 더 안정적입니다.
- 결과 폴더가 같은 NTFS 드라이브라면 하드링크 모드를 쓰면 복사 시간과 추가 저장공간을 크게 줄일 수 있습니다.

## 개인정보

얼굴 특징값과 분류 캐시는 로컬 PC의 `%LOCALAPPDATA%\PhotoRefSorter\`에 저장합니다. 사진을 별도의 얼굴 인식 서버로 업로드하지 않습니다.
