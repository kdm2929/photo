# PhotoRefSorter v0.4

레퍼런스 사진을 기반으로 대량의 사진 폴더에서 같은 인물을 찾아 자동으로 분류하는 Windows용 로컬 사진 분류기입니다.

## v0.4 Fast Scan

- `os.scandir` 기반 빠른 폴더 열거
- 대형 JPEG 1/2 축소 디코딩으로 I/O + 디코딩 비용 절감
- CPU에 맞춘 2~8개 병렬 얼굴 분석 워커
- SQLite 얼굴 임베딩 캐시
  - 파일 경로 + 크기 + 수정시간이 같으면 이미지를 다시 읽지 않음
  - 레퍼런스 인물을 새로 추가하거나 임계값을 바꿔도 기존 사진 캐시 재사용
- 모든 레퍼런스를 하나의 NumPy 행렬로 합쳐 빠른 매칭
- 처리 속도, 캐시 사용량, 새 AI 분석 수, ETA 실시간 표시
- 중단 버튼
- 레퍼런스 평균 일관성 / 개별 기준 유사도 표시
- 여러 얼굴이 있는 레퍼런스는 가장 큰 얼굴을 사용하고 경고 표시
- 안전한 파일 복사 / 같은 드라이브 NTFS 하드링크 모드
- `_확인필요`, `_미확인`, `_얼굴없음`, CSV 결과 유지

## 추천 설정

처음 수만 장을 분석할 때는 `병렬 분석: 자동`, `분석 캐시 사용`을 켜두는 것을 권장합니다.
첫 스캔은 실제 AI 얼굴 분석 시간이 필요하지만, 두 번째부터 변경되지 않은 사진은 캐시된 얼굴 임베딩으로 재분류됩니다.

## 사용 순서

1. `인물 & 레퍼런스`에서 이름을 추가합니다.
2. 인물당 5~20장 정도의 레퍼런스 사진을 등록합니다.
3. `빠른 자동 분류`에서 원본 사진 폴더를 선택합니다.
4. 필요하면 결과 생성 방식과 병렬 워커 수를 조정합니다.
5. `빠른 분류 시작`을 누릅니다.

원본 사진은 삭제하거나 이동하지 않습니다.
