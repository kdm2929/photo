# PhotoRefSorter v0.6 Pro — Smart Photo Library

레퍼런스 사진을 기반으로 대량의 사진/영상에서 같은 인물을 찾고, 검토 결과를 다시 학습해 갈수록 정리하기 쉬워지는 Windows용 로컬 사진 관리/분류 앱입니다.

## v0.6 Pro에서 달라진 점

### 사진 중심 고급 UI
- 홈 대시보드: 전체 미디어, 등록 인물, 인식 얼굴, 검토 대기, 미확인 얼굴 요약
- 수만 장 대응 가상화 갤러리
- 비동기 썸네일 생성 및 디스크 캐시
- 커스텀 사진 카드 렌더링
  - 선택/호버 상태
  - 얼굴 수 배지
  - 영상 배지
  - 즐겨찾기 배지
- 사진 카드 크기 실시간 줌
- 검색 입력 디바운스 적용으로 대형 라이브러리에서도 불필요한 DB 질의 감소
- 우측 인스펙터 패널에서 사진 정보, 얼굴별 Top 3 후보, 앨범 확인
- 다크/라이트 테마
- 페이지 전환 페이드 애니메이션
- 단축키: Ctrl+1~5 페이지 이동, Ctrl+L 검색, Ctrl++/Ctrl+- 갤러리 확대/축소

### 빠른 검토
- 애매한 얼굴을 큰 사진 + 얼굴 crop으로 표시
- Top 3 인물 후보와 점수 표시
- 키보드 `1/2/3`으로 바로 확정/학습
- `X`로 1위 후보를 negative sample로 학습
- `← / →`로 검토 항목 이동

### 인물 프로필
- 대표사진
- positive / negative 레퍼런스 수
- 평균 레퍼런스 품질
- 인물별 자동 threshold
- 최근 인식 사진
- 가장 많이 혼동되는 다른 인물
- 혼동 점수 차가 작은 경우 경고

### 스마트 미확인 인물 그룹
- 미확인 얼굴을 자동 클러스터링
- 반복 등장하는 동일 인물을 그룹으로 표시
- 새 이름을 한 번 지정하거나 기존 인물과 병합
- 그룹 내부에서 품질과 다양성을 기준으로 최대 24개의 대표 얼굴만 자동 학습

### 수만 장 고속 처리
- `os.scandir` 기반 빠른 폴더 열거
- 대형 JPEG 축소 디코딩
- SSD/HDD/CPU 상태 기반 워커 자동 튜닝
- 최대 8개 병렬 얼굴 분석 워커
- SQLite WAL 얼굴 임베딩 캐시
- 변경되지 않은 사진은 재디코딩/재분석하지 않음
- pHash 완전 중복 사진은 기존 얼굴 분석 결과 재사용
- 실시간 처리 속도 / ETA / 캐시 적중 / 신규 AI 분석 수 표시
- 작업 중단 후 재실행 시 기존 분석 캐시 재사용
- 같은 NTFS 드라이브에서는 하드링크 분류 옵션

### 인식 정확도
- 여러 positive 레퍼런스
- negative sample 학습
- 레퍼런스 품질 가중치
- 인물별 자동 threshold
- centroid + 개별 레퍼런스 동시 비교
- Top 3 후보와 1위/2위 margin으로 닮은 인물 오분류 억제
- 얼굴 품질 평가: 얼굴 크기, 선명도, 검출 신뢰도, 정면성

### 미디어 지원
- JPG / JPEG / PNG / BMP / WebP / TIFF
- HEIC / HEIF
- AVIF
- GIF
- RAW: DNG / CR2 / CR3 / NEF / ARW / ORF / RW2 / RAF / PEF / SRW
- 영상: MP4 / MOV / M4V / AVI / MKV / WebM
- 영상은 대표 구간을 샘플링하고 반복 얼굴 임베딩을 줄여 저장/비교량 절약

### 앨범 / 중복 / 작업 기록
- 사용자 앨범/이벤트 생성
- 여러 사진 일괄 앨범 추가
- pHash 중복 및 유사 연사 후보 확인
- 최근 분류 작업 기록
- 마지막 분류 작업 되돌리기
- 존재하지 않는 원본의 캐시 정리

## 업그레이드 호환성

기존 `%LOCALAPPDATA%\PhotoRefSorter\people.sqlite3`가 있으면 새 `library.sqlite3`로 인물/레퍼런스를 자동 이전합니다. 분석 캐시와 학습 데이터는 앱 업데이트 후에도 유지됩니다.

## 권장 사용 흐름

1. `인물`에서 사람과 레퍼런스를 등록합니다.
2. `대량 분류`에서 최초 스캔합니다.
3. `빠른 검토`에서 애매한 얼굴을 `1/2/3/X`로 빠르게 학습합니다.
4. `미확인 얼굴`에서 반복 등장 인물을 그룹 단위로 이름 붙입니다.
5. `모든 사진`에서 타임라인/인물/앨범 필터로 사진을 관리합니다.
6. 다시 분류하면 기존 얼굴 임베딩 캐시를 재사용해 훨씬 빠르게 재매칭합니다.

## 개인정보

얼굴 특징값, 썸네일, 분류 캐시는 로컬 PC의 `%LOCALAPPDATA%\PhotoRefSorter\`에 저장합니다. 사진이나 얼굴 특징값을 별도의 얼굴 인식 서버로 업로드하지 않습니다.
